POS shop identity (Spanish simplified invoice)
==============================================

**Table of contents**

.. contents::
   :local:

Glue between ``pos_config_shop_identity`` and ``l10n_es_pos_oca``: prints
the simplified invoice title and number on one bold receipt line
(``Simplified invoice: PREFIX0001``). The original two-line block from
``l10n_es_pos_oca`` is hidden.

Auto-installs when both dependencies are installed. No extra settings.
